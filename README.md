# README Studio

English | [简体中文](README.zh-CN.md)

A simple, privacy-friendly README generator for open-source projects. Fill in a few details, preview live, copy or download a bilingual README.

**[Public demo](https://pangxueyuan2-creator.github.io/oss-readme-studio/)** — no account needed.

Everything runs in the browser. Nothing is uploaded.

## Features

- Live Markdown preview
- Presets for common project types
- Optional English + Chinese output
- Local quality score for missing sections
- Can also audit an existing README via CLI or GitHub Action

## Run locally

Node 22+.

```bash
git clone https://github.com/pangxueyuan2-creator/oss-readme-studio.git
cd oss-readme-studio
npm install
npm run dev
```
