# Changelog

All notable changes are documented here.

## [Unreleased]

## [0.4.0] - 2026-08-02

### Added

- A deterministic README readiness audit in the web app.
- A reusable GitHub Action and command-line audit entry point.
- Simplified Chinese project documentation.
- Dependabot configuration, a pull-request template, and a code of conduct.
- Tests for complete, incomplete, and project README audits.

## [0.3.0] - 2026-08-02

### Added

- Focused templates for CLI tools, web apps, libraries, and data projects.
- A public GitHub Pages build that does not require an account.
- Maintainer responsibilities and an honest project-impact statement.
- Tests that cover template selection and isolation.

### Changed

- Shared the same interactive application component between the main deployment and public demo.

## [0.2.0] - 2026-08-02

### Added

- Unit tests for README generation, bilingual output, and fallback content.
- GitHub Actions verification for every pull request and push to `main`.
- Structured issue forms, a public roadmap, and a security policy.

### Changed

- Extracted README generation from the page component into a reusable module.
- Replaced obsolete starter-template tests with product-specific rendering checks.

## [0.1.0] - 2026-08-02

### Added

- First working README Studio release.
- Live generation, bilingual output, copying, and Markdown download.
