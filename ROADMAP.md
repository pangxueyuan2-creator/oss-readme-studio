# Roadmap

README Studio is maintained in small, testable releases. Priorities are based on reproducible user needs rather than feature count.

## Now — 0.2

- [x] Extract and test the README generator.
- [x] Add continuous integration for builds, linting, and tests.
- [x] Add structured bug and feature request forms.
- [x] Document private vulnerability reporting.

## Next — 0.3

- [x] Add templates for CLI tools, libraries, web apps, and data projects.
- [x] Publish a public demo that does not require an account.
- [x] Document project impact and maintainer responsibilities.
- [ ] Add accessible rendered-Markdown preview alongside the source view.
- [ ] Add import and export for reusable local presets.

## Later

- [ ] Add community-maintained translations.
- [ ] Add optional checks for missing installation and contribution details.
- [ ] Publish anonymized, opt-in usability findings only if a privacy-preserving method is available.

Current work is tracked through [GitHub issues](https://github.com/pangxueyuan2-creator/oss-readme-studio/issues). Contributions should begin with a focused issue.
