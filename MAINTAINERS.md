# Maintainers

README Studio uses a simple maintainer model while the community is small.

## Current maintainer

- [@pangxueyuan2-creator](https://github.com/pangxueyuan2-creator) — project direction, issue triage, pull-request review, releases, and security coordination.

## How decisions are made

- Small fixes and documentation changes are decided through focused pull requests.
- User-facing changes should start with an issue and include tests where practical.
- Decisions favor accessibility, local-first privacy, and a small dependency footprint.
- Significant changes remain open for public feedback before merging when the project has active community participants.

Consistent contributors may be invited to help triage or maintain an area of the project. Maintainer status is based on sustained, constructive participation rather than commit count alone.
