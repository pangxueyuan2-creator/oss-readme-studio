# Code of Conduct

README Studio welcomes beginners, maintainers, translators, and documentation contributors.

## Our standards

- Be respectful, specific, and patient.
- Critique ideas and code without attacking people.
- Make room for different experience levels, languages, and backgrounds.
- Do not harass, threaten, discriminate against, or expose private information about others.

## Scope and enforcement

These expectations apply in repository issues, pull requests, discussions, and other project spaces. Maintainers may edit or remove harmful content and may temporarily or permanently restrict participation when necessary.

For a private conduct report, contact the current maintainer through the contact options on their GitHub profile. Do not publish sensitive personal details in a public issue. Reports will be reviewed as promptly and impartially as possible.
